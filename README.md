## 프로젝트 소개
본 프로젝트는 대구은행의 금융 데이터를 분석하여 중장년층(40대 이상) 고객의 소비 패턴을 파악하고, 해당 연령대의 니즈를 충족시킬 수 있는 맞춤형 카드 상품을 제안하는 것을 목표로 합니다.

### 주요 내용:
1. **소비 패턴 분석**:  
   - 각 세대별 소비 데이터를 분석해 가장 많이 사용하는 가맹 업종을 파악  
   - 통계 분석 및 시각화를 통해 연령대별 소비 패턴 차이 확인  
2. **신규 카드 기획**:  
   - 세대별 소비 패턴을 기반으로 40대 이상 고객을 위한 카드 혜택 설계  
   - 카드 혜택 3가지 제안 (가안):  
     1. **나를 위한 혜택 (I)**  
     2. **우리를 위한 혜택 (US)**  
     3. **혜택 커스텀 (ALL)**
